# Site Pessoal / Portfólio — Kauã Silva Mattoso

Projeto individual (CP3): site com 5 páginas, responsivo, com JavaScript e `localStorage`.

## Páginas
`index.html` · `curriculo.html` · `formulario.html` · `multimidia.html` · `graficos.html`

## Recursos do CP3
- **Tema claro/escuro** salvo no `localStorage` (vale para todas as páginas).
- **Formulário** com validação em JavaScript, mensagens de erro por campo e feedback visível.
- **Rascunho automático** do formulário e **histórico de mensagens** salvos no navegador.
- Gráfico em Canvas desenhado via `js/scripts.js`.
